Privacy Policy

Effective 20 October 2026.

Geryza's Universe is a YouTube channel run by one person — me, the channel owner. This policy covers this website and the channel's publishing tool: a program I run on my own computer to publish and measure the channel's videos. The tool uses the YouTube API Services. Google's handling of data is covered by the Google Privacy Policy, and using YouTube is governed by the YouTube Terms of Service.

Who uses the tool

Only the channel owner, on the channel's own Google account. The tool is not offered to anyone else, and no one else can sign in to it.

What the tool accesses

When I sign in with Google, I allow the tool to:

  • upload and manage the channel's own videos — the video file, title, description, tags, category, language, captions, thumbnail, privacy status and the AI-content disclosure;
  • read the channel's own videos back, to check each one was published as approved;
  • read the channel's analytics and reports — views, watch time, audience retention, impressions, click-through rate and traffic sources. These are totals for the channel and its videos; they identify no individual viewer;
  • read the comments on the channel's videos, together with the public display name YouTube shows beside each, and post or moderate comments as the channel.

The tool never asks for, sees or stores a Google password.

What it keeps, where, and for how long

  • The sign-in token stays on my computer, readable only by my user account. It is never published or shared.
  • Analytics and report data are kept in my private records, so episodes can be compared over time. YouTube's policies allow these statistics to be kept beyond 30 days; every 30 days the tool confirms it is still authorised to read them and that each video still exists, and it deletes the statistics of a video that no longer exists.
  • Comments are kept on my computer only so I can read and answer them. A stored copy is refreshed or deleted within 30 days; a comment deleted on YouTube is deleted from my copy at the next refresh. Comments are never published elsewhere, sold, or used for advertising.

Sharing

The tool shares no YouTube data with anyone. Nothing is sold, and there are no advertising or analytics partners. Videos and comments the tool posts are public on YouTube, exactly as if they were posted in YouTube Studio.

Cookies and this website

This website sets no cookies, runs no scripts and loads nothing from other sites. It is hosted by GitHub Pages; GitHub may keep server logs under the GitHub General Privacy Statement. The publishing tool runs on my computer and stores nothing on anyone else's device.

Revoking access and deleting data

  • Access the tool has been given can be revoked at any time on Google's security settings page, security.google.com/settings/security/permissions. Once revoked, the tool can read nothing more, and data it holds about that account is deleted within 30 days.
  • If you commented on a video and want my stored copy removed, delete the comment on YouTube, or write to the address below: it is deleted within 7 days of your request.

Questions and complaints

Write to gery.memes.official@gmail.com.

Changes

When the tool's use of data changes, this page changes first, and its effective date moves with it.
