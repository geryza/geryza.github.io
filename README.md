# Geryza's Universe — website

The public pages of the YouTube channel **Geryza's Universe**: the home page, the
[privacy policy](privacy.html) and the [terms of service](terms.html) of the
channel's publishing tool, served by GitHub Pages at https://geryza.github.io/.

Plain HTML and one stylesheet: no build step, no scripts, no cookies, nothing
loaded from other sites (`.nojekyll` turns off GitHub's Jekyll processing).
